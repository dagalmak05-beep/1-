# Калькулятор зарплаты от продаж

Простая консольная программа для расчёта выплаты на сотрудника по формуле:

`сумма продаж отдела * 1% / количество людей в отделе`

## Запуск

```bash
python3 salary_calculator.py
```

Далее вручную вводятся:
- количество отделов;
- название отдела;
- сумма продаж отдела;
- количество сотрудников в отделе.

После ввода программа покажет выплату на одного человека по каждому отделу и общие итоги.
